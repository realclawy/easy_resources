## How to use
### Main commands
Easy Resources has two command that are of big importance:

`easyresources make <set>` -> What this command does is guide you through the process of making a set, which is a configuration file which tells the program what to display and in what order!
As of a personal to do, I should probably transform this into a TUI, but I don't think this project is relevant enough, is it?

`easyresources run <set>` -> What this command does is run the set you made using (or not) the `make` command. Yeah that's it

### Other commands
Easy Resources also has these other commands which are more QoL than anything:

`easyresources delete <set>` -> deletes the set you tell it to delete

`easyresources rename <set>` -> renames the set you tell it to rename to the thing you tell it when it prompts the question
